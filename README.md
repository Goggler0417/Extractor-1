# Hitomi 추출기 v1.0

## 실행

1. ZIP을 풀고 Mac에서 `start.command`를 더블클릭합니다.
2. 브라우저에 편집 목록이 열립니다. 자동으로 열리지 않으면 터미널에 표시된 주소를 복사해 엽니다.

터미널에서 실행하려면 압축을 푼 폴더로 이동한 다음 `python3 hitomi-extractor.py`를 실행합니다. Python 3.9 이상이 필요하며 별도 패키지는 없습니다. 종료하려면 터미널에서 Ctrl+C를 누릅니다.

## 사용

1. 작품 링크를 한꺼번에 붙여넣고 **링크 추가**를 누르거나 **파일 추가**에서 DOCX, HTML, JSON, TXT, CSV, MD 등을 선택합니다. DOCX에 숨은 하이퍼링크 대상도 읽습니다. 파일당 최대 12MB, 목록은 최대 3,000작품입니다.
2. **정보 수집**으로 제목, 작가, 그룹, 형식, 시리즈, 언어와 페이지 수를 채웁니다. 재생시간은 원본 메타데이터에 있을 때 채웁니다. 같은 작품 번호의 주소는 한 행으로 합칩니다.
3. 표에서 바로 수정합니다. 작가·그룹·시리즈가 여러 개라면 `|`로 구분하세요. 재생시간은 초, `mm:ss`, `hh:mm:ss`를 받습니다. 수집이나 재수집은 직접 수정한 칸을 보존합니다.
4. **JSON 내보내기** 또는 **CSV 내보내기**를 누릅니다. 실패하거나 아직 수집하지 않은 행도 현재 값과 상태를 포함해 내보냅니다.

## 출력

JSON은 `format: "hitomi-metadata"`, `version: 1`과 `items` 배열을 담습니다. 각 작품에는 `id`(문자열 작품 번호), `url`, `title`, `artists`, `groups`, `type`, `series`, `pages`, `durationSeconds`, `language`, `note`, `status`가 들어갑니다. 작가·그룹·시리즈는 배열이며, 페이지와 재생시간은 값이 없을 때 null입니다. Bookmark System 전체 백업 포맷과는 별개입니다.

작품 이미지나 영상은 내려받지 않습니다. 링크가 담긴 파일의 내용은 로컬에서 읽으며 수집할 때 해당 작품의 메타데이터만 요청합니다. 목록은 브라우저를 새로고침하거나 닫으면 사라지므로 작업이 끝나면 내보내세요. JSON을 다시 넣으면 링크 목록을 읽습니다. 사이트 응답이나 접속 상태에 따라 일부 정보가 비거나 수집이 실패할 수 있습니다.
